PDF Split

Split a PDF into two files for double-sided printing on a single-sided printer: print the odd file, put the stack back in flipped, then print the even file - it's already in the right order, no reshuffling needed.

Everything runs in your browser. Your file is never uploaded anywhere.

Drop a PDF here or click to choose a file

Odd pages Even pages Both (.zip)
  1. Print the odd pages file.
  2. Take the printed stack and put it back in the paper tray, flipped onto its back.
  3. Print the even pages file — the pages inside are already reordered to match.

Prefer the terminal? The same tool exists as a Python CLI on GitHub. ( Don't forget to star the repo 🙄 )

fasterfetch

A neofetch-style system info tool I wrote in C — zero dependencies, no subprocesses, it reads /proc and /sys directly. This page is its browser edition: it fetches your machine's info using standard browser APIs and renders it in the same style.

Everything runs in your browser. No IP lookup, no geolocation, no network calls — nothing is stored or sent anywhere.

$ fasterfetch -t

This is the real thing's little sibling — the original is a zero-dependency C CLI on GitHub, with distro logos, themes, borders and a JSON config. ( Don't forget to star the repo 🙄 )
